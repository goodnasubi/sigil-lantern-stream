# sigil-lantern-stream

YouTube のような動画配信プラットフォームを提供する、Sigil 部品群のアプリケーション層の部品。lantern＝幻灯機（マジックランタン）。光で映像を映し出す原初の装置を名前の由来とし、stream＝配信を示す。

## 役割

- 動画の受け入れ（アップロード）、メタデータとカタログの管理、変換パイプラインの段取り、適応ビットレート配信（HLS 等）の窓口、再生の仕組みを担う
- 役割は「動画の公開と再生」に一つに絞る。コメント・推薦・収益化・ライブ配信は初期範囲に入れず、後段で扱う
- 部品群を「使う側」に立つ初めてのアプリケーション層の部品で、疎結合な部品の組み合わせで本格的なサービスが作れることの実証（ドッグフーディング）を兼ねる
- 将来、所有者の VTuber キャラクター「シジ」の動画の置き場になりうる

## 既存部品との分担

- 変換（トランスコード）の実行: sigil-herald-queue へジョブを投入し、sigil-summon-functions や sigil-container 上のワーカーが実行する。本部品はパイプラインの段取りまで
- ファイルの保存と配信: 変換済みファイルと HLS のセグメントは sigix が静的配信する（大容量バイナリのオブジェクトストレージ専用部品は現状なく、当面は sigix の静的ファイルとして置く）
- 認証: 投稿者アカウントは sigil-rune-auth
- メタデータの保存: sigil-db
- 入口の経路: sigil-atlas-dns → sigil-shield-tls → sigil-aegis-waf → sigix の主経路に乗る
- 監視: sigil-argus-observe

## 状態

計画・リポジトリ作成済み（2026-11-23 に採用決定）。実装はこれからで、着手時は ADR 起草の段から始める。依存する部品（sigix、summon-functions、herald-queue、rune-auth 等）の実装が前提になるため、着手時期は実装順の再考で決める。
